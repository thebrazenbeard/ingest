# Security Policy

Security fixes target the current default branch unless a maintained release is explicitly documented.

Do not publish exploit details, credentials, private data, or proof-of-concept material in a public issue. If GitHub exposes **Report a vulnerability**, use it. Otherwise open a public `Security contact requested` issue containing no sensitive details.

For Ingest-specific boundaries, see [`docs/SECURITY_MODEL.md`](docs/SECURITY_MODEL.md).
